# AniHub — мобильное приложение (Capacitor)

Нативный путь для телефонов:
- **Android** — `npx cap add android` → `npx cap build android` — APK (через Android Studio).
- **iOS** — `npx cap add ios` — нужен Mac/Xcode.

Пока демо: веб-сайт (PWA). Связка «сайт ↔ приложение»: все клиенты смотрят через один фронт — синхронизация всегда.

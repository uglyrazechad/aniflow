# AniHub — нативное приложение (Tauri)

Реально нативный десктопный клиент (не Electron):

- **Автономность:** если фронт (`http://localhost:3000`) выключен, приложение сам стартует `node server.mjs` (он поднимает фронт + Next).
- **Синхронизация:** все приложения и веб-сайт — один фронт — через WebSocket рассылают все события (плеер, чат, участники).
- **Без сайта:** приложение работает независимо от публичного сайта — фронт внутри.

## Сборка (нужна Rust toolchain — [rustup.rs](https://rustup.rs))

```powershell
npm install            # упаковывает десктоп приложение
npx tauri build        # собирает exe
```
